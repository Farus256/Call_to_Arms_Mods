# Сверка требований и текущей сборки — 05.10.2026

Исходное задание выполнено **частично**. Код содержит рабочие по статическим и модельным проверкам элементы реализма, но не полную модель морали и выживания. Проверка файлов не подтверждает качество поведения в настоящем бою.

Проверено состояние после `a97ad31`. Заново извлечены 14 344 ресурса текущей игры и зависимостей Workshop без переопределений UFB; для сравнения использован каталог `_survival_work/audit-20261005`. Все 11 043 файла двух локальных модов совпадают с установленными по SHA-256. Два дополнительных установленных файла — старые резервные `.bak`, не игровые `.inc`. Все 10 088 пород совпадают с манифестом, их исходники совпадают со свежим снимком. Новых, исчезнувших или устаревших пород в проверенном наборе нет.

## Ошибки и проверки

Новых ошибок в пройденных сценариях не обнаружено. Это не доказательство отсутствия всех ошибок сборки.

- 10 567 проверок тактического слоя: реальные SDL-данные в ограниченной модели событий, Lua с подставным BotApi.
- 45 проверок в 11 сценариях логики ИИ.
- 444 миссионных файла, 13 проверок валидатора типов параметров: без проблем.
- 20 284 проверки текущих ресурсов против заново извлечённой игры; повторено для установленного UFB. Штатные движение и формации совпадают; все профили актуальны.
- Полный синтаксический разбор 10 952 локальных SDL и 16 Lua 5.1 — без ошибок, результаты в `current-state.json`. Проверка раскрытия условных макросов: 13 826 эффективных файлов, 1 070 определений, 0 синтаксических ошибок, 0 найденных случаев вложенных mod и 0 неразрешённых условных вызовов. Неизвестные движковые команды этим анализатором не исполняются.
- Установщик проверен на отдельном тестовом каталоге: dry run, установка, повтор, откат, защита последующих пользовательских правок и выходов за каталог.
- Исходный PBR и отдельный прототип: все 16 компиляций FXC успешны, новых предупреждений прототип не добавил. Компиляция не доказывает правильность изображения.

Найдены и исправлены ошибки **документации**: README и индекс называли отменённые изменения движения/PBR последним пакетом, удалённые AP/AT-процедуры описывались как действующие, старый манифест из 946 файлов назывался полным текущим. Исторические отчёты сохранены и помечены; актуальный охват указан здесь. Добавлен повторяемый аудит `tools/audit-current-state.cjs`.

Для HP существенно: в текущих исходниках Easy имеет health 0,5 для any/enemy, Heroic — 1,10 в any; Normal/Hard/Multiplayer используют 1,0. Это существующие параметры сложности, а не дополнительная UFB-прибавка. 45 пород задают способность health явно; это процентные уровни той же сжатой таблицы, а не обход нового здоровья. Сценарные исключения, нестандартные модели и загруженные сохранения требуют отдельной проверки. Считать каждый юнит во всех режимах одинаковым по итоговой живучести неверно.

## Графика и эффекты с небольшой добавкой нагрузки

Активный PBR оставлен исходным. В двух локальных модах нет шейдерных переопределений. Прототипы из `_survival_work` не являются установленными модами.

Счётчик FXC для трёх затронутых вариантов: normal_specular 757 → 758, foliage 766 → 767, shadows 778 → 779. [Данные](graphics-cost.json). Число instruction slots не является процентом изменения FPS.

| Вариант | Что подтверждено | Ограничение |
|---|---|---|
| Смягчить блики старых материалов | Прототип добавляет `roughness = max(roughness, 0.35)` в `universalT`. В скомпилированном normal_specular число instruction slots выросло с 757 до 758. Ветви полноценных PBR-материалов в проверенных вариантах побайтно совпадают. | Перспективно по вычислительной цене, но может сделать металл слишком матовым. Это кандидат для A/B, не подтверждённое исправление зимнего потемнения или всех пересветов. Не установлен. |
| Проверять mip-цепочки конкретных проблемных текстур | 17 ранее исправленных DDS уже входят в установленный мод. Полноценные mip-уровни позволяют фильтровать дальние поверхности; заново создавать те же цепочки не нужно. | Новые текстуры следует выбирать по артефактам и заголовкам. Массовая переделка альфы/частиц без кадра может испортить эффекты. |
| Точечно исправлять материалы и LOD | При расстояниезависимом потемнении полезно сравнить материал ближнего/дальнего LOD на одинаковом освещении, затем менять конкретный ресурс. | Точная причина зимнего потемнения без воспроизведения не установлена. Глобальное затемнение света уже давало плохой результат. |
| Настраивать вид эффекта без увеличения числа частиц | Цвет, размер и скорость затухания существующего эффекта — кандидаты без добавления новых эмиттеров. | Даже больший размер прозрачного спрайта увеличивает заполнение экрана; FPS нужно измерить. Конкретные изменения пока не выбраны без визуального сравнения. |

Текущий профиль RTX 3080/1920×1080 уже использует MSAA 8x, anisotropic16x, высокие тени/SSAO/эффекты, parallax, ultra-воду; film grain и DOF выключены. Простого свободного повышения качества по этим настройкам нет. Увеличение теней, дальности, плотности дыма и числа частиц нельзя назвать малозатратным без замеров.

Особенно важно для длинных боёв: у `ufb_blood_spot_*` и `ufb_bloodstain_*` задано время жизни 9999 с. Сохраняемые следы могут накапливать нагрузку; прежде чем добавлять больше дыма и крови, нужен замер длительного боя. В этом аудите время жизни и количество следов не менялись.

В этом аудите игра и новый бой не запускались; FPS, визуальные сравнения, фактическая загрузка HP, безопасность маршрутов и сетевой синхронизм не подтверждены. Последний доступный `game.log` датирован 04.10.2026 20:18:19: в нём нет активации Workshop/UFB, поэтому он не доказывает работу нынешней сборки. Сам флаг `-showmodinfo` не доказывает ни диагностический-only запуск, ни причину отсутствия Steam.

Для приёмки нужны новые бои: одинаковые призывник/ветеран под винтовочным и взрывным огнём, 40 с восстановления; приказ игрока и прямое управление; ПТ-оружие на границе дальности; два флага и один флаг Conquest; ящик/грузовик на границе снабжения; разворот группы на 180°; зимняя и летняя сцена через SMS на нескольких расстояниях. Не реализованные командирские потери и эвакуация не могут пройти положительную приёмку до появления кода.

Из корня репозитория; зависимости уже находятся локально в `_ai_work/node_modules` (Fengari и luaparse). Снимок извлечённых ресурсов — рабочий материал, в Git не включён.

```powershell
$env:NODE_PATH=(Resolve-Path '../_ai_work/node_modules').Path
node tools/audit-current-state.cjs '../_survival_work/audit-20261005'
node tools/verify-tactical-balance.cjs
node tools/verify-ai-logic.cjs
node tools/validate-mission-ai.cjs
node tools/verify-combat-audit.cjs '../_survival_work/audit-20261005'
```

Первый инструмент сверяет локальные моды с установленными, профили со снимком, разбирает SDL/Lua и фиксирует охват. Снимок перед следующим аудитом надо извлекать заново; проверка вчерашнего снимка не обнаруживает сегодняшнее обновление Workshop. Результаты: [состояние файлов](current-state.json), [проверка установленного UFB](installed-verification.json), [условные макросы](macro-audit.json), [компиляции PBR](../combat-audit/pbr-probe.json).
