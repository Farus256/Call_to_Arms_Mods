# Сохранение PBR и удаление переопределения UFB

По просьбе пользователя оригинальный Workshop PBR оставлен включённым. Восстановлены исходные 10 файлов из `3548575715/resource/shader`; SHA256 каждого совпадает с сохранённой копией. Оригинальный PBR `dx10/pbr/light.hlsl` имеет SHA256 `3f78dd3995d493e40868fd551d6331a2001eabf22c29f341dd4757e28b8cabf1` и не содержит добавленных UFB ограничителей бликов.

Причина чёрных объектов была в оставшемся установленном переопределении UFB: `mods/ultimate_frontline_bundle/resource/shader/dx10/pbr/light.hlsl` (SHA256 до удаления `AEDF782BC52C7EC4CC2E2E1D897EDE493D8152970B0FFE559EC68388EEDB12CB`). Файл удалён из установленного UFB; описание установленного мода синхронизировано с исходниками и больше не заявляет PBR-патч. Кэш `dx11.0` игры очищен, чтобы шейдеры пересобрались при запуске. Перед изменением файл патча, прежний `mod.info` и все 459 файлов кэша (4 043 384 байта) сохранены в `_survival_work/shader-restoration-20261004`.

Проверка после изменений: все 10 исходных файлов PBR совпадают по SHA256; UFB override отсутствует; кэш пуст; описание установленного UFB не упоминает старый патч. Компиляция штатных вариантов PBR через FXC ранее проходила для шести вариантов. Визуальный результат в игре после запуска через SMS Launcher в этой сессии не проверен.
