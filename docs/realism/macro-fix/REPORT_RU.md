# Второе исправление Nested mods: косвенные макросы и списки отрядов

Дата: 02.10.2026. Исправление установлено в `ultimate_frontline_bundle`. Один файл заменён, два новых переопределения добавлены. Оригинальная игра и Workshop-архивы сохранены. Игра после исправления не запускалась по указанию пользователя.

## Что подтвердил новый журнал

Журнал `C:\Users\velik\AppData\Local\digitalmindsoft\gates of hell\log\game.log`, изменённый 02.10.2026 в 17:11:38, показывает:

```
Nested mods not supported (eSDLReader.cpp:519)
/set/stuff/gun/150mm_l11
/set/stuff/gun/150mm_sig33
define 'accuracy_spg'
define 'curve_direct'
```

В исходном `150mm_sig33` условие `(mod not "mp")` вызывает `accuracy_spg`. Этот макрос вызывает `curve_direct`, где мной были добавлены условия режима. При раскрытии два `mod` оказываются вложенными. Восстановление одного файла sIG33 в предыдущем исправлении не устранило изменённый общий макрос.

Предыдущая проверка макросов сравнивала только прямые вызовы и только файлы двух локальных модов. Она пропустила промежуточный макрос и вызовы из оригинальных/унаследованных ресурсов. Исторический результат 6 604 проверок поэтому не подтверждал отсутствие такого сбоя; он отмечен как заменённый.

## Проверяемые пределы

Анализ использует локальный разбор SDL и модель пространств имён макросов: семейные `.presets` и явные `include`. Это не полный эмулятор движка. Условия проверяются консервативно по всем ветвям. Последующий запуск, ошибки за пределами охваченных ресурсов, реальный бой, сетевой режим и производительность после исправления пока не проверены. Успешный запуск не заявляется.

Все три установленных файла сверены по SHA-256. Предыдущая версия заменённого `.presets` сохранена локально; исходные списки отрядов тоже сохранены в рабочей папке. Актуальные хеши двух модов опубликованы в общем снимке.

- [payload.json](payload.json) — хеши трёх ресурсов, отменённые условия и точные восемь исправлений.
- [verification.json](verification.json) — результаты и ограничения проверки.
- [audit-before.json](audit-before.json) — найденные цепочки до исправления.
- [audit-after.json](audit-after.json) — повторный анализ подготовленного пакета.
- [current-files.json](../../current-files.json) — актуальные хеши ресурсов обоих модов.
