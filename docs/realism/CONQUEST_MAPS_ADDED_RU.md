# Дополнительные карты Conquest

Добавлены отдельные миссии `campaign_capture_the_flag` для трёх карт основной игры:

| Карта | Папка | Окружение |
| --- | --- | --- |
| Fields | `4v4_fields` | открытая местность, категория `desert` |
| Rikila | `4v4_Rikila` | лесная местность, категория `wood` |
| Sikovitsy | `4v4_Sikovitsy` | зимняя местность, категория `winter` |

Уже существовавшие 114 миссий Conquest были подключены. Дополнение увеличивает файловый каталог до 117. Обнаружение новых миссий игрой ожидается через штатные `campaign_capture_the_flag.info` с `mapSelection 1`; фактическое появление в кампании ещё требует проверки в игре. Новых зависимостей от DLC нет.

## Что сделано

- Для каждой карты выбраны пять существующих целей и сохранены восемь входов из текущей модовой multiplayer-миссии. Исходные `battle_zones.mi`, рельеф, навигация и текстуры не изменены.
- Использован текущий совместимый шаблон `dcg_shaforovo`: роли и этапы гарнизона, подкрепления, самолёты, экипажи, укрепления и погодные скрипты. Объектам выданы новые идентификаторы без совпадений с объектами исходного рельефа.
- Наземные позиции и высоты проверены по исходной навигационной сетке. Сохранённые привязки к укрытиям перенесены вместе с соответствующими укреплениями; непригодные привязки убраны, оставляя обычное поведение ИИ.
- Дополнительные точки Hortens Frontline встроены в новые миссии и перенесены на их рельеф. Переходы сохранены и проверены; точки ухода с удалением объекта размещены у соответствующих границ карты.
- Для начального Lua-гарнизона построены восемь вариантов размещения с существующей системой безопасных позиций. Отдельно отодвинуты опасные встроенные слоты гарнизона: они могут использоваться до выбора входа игрока, поэтому проверены относительно всех восьми входов сразу.
- Использованы текущие расчётные дальности: пехота 210 м, техника 550 м, коэффициент бота 1,02 и запас на стартовую область/разброс. При этих настройках недостаточно удалённых позиций на трёх добавленных картах не обнаружено. Дальнобойная артиллерия за пределами этого профиля не покрывается гарантией расстояния.

Grassland и Winter Walk не включены: при текущих модовых стартовых координатах для встроенной техники не удалось найти общий безопасный резерв относительно всех входов. Это не утверждение о невозможности адаптации этих карт другим способом.

## Файлы и настройка

На каждой из трёх карт добавлены только `campaign_capture_the_flag.mi`, `campaign_capture_the_flag.info` и `ufb_garrison_layout.inc`: всего девять игровых файлов. Точные пути и исходные SHA256 перечислены в [CONQUEST_MAPS_ADDED.json](CONQUEST_MAPS_ADDED.json).

Чтобы исключить одну карту из последующих выборок кампании, в её `.info` поставьте `mapSelection 0`, как для исключённых штатных карт. Уже запланированные бои сохранения этим не переписываются. Для проверки появления новых карт предпочтительна новая кампания.

Дальности и запас безопасной расстановки задаются в `tools/garrison-layout.json`. После изменения необходимо заново сгенерировать позиции: это файловая расстановка, а не постоянный пересчёт во время боя.

## Проверка и ограничения

Файловые проверки: три карты, 24 входа, 9555 исходных/производных точек маршрута, уникальность идентификаторов, разрешение ссылок на маршруты и экипажи, сохранение этапов/ролей гарнизона, исходных multiplayer-миссий, высоты и тип грунта, диапазоны безопасности начального гарнизона. Сохранено 179 привязок к укрытиям. Дополнительно проверен SDL-синтаксис параметров ИИ: 564 файла, ошибок не найдено.

**В самой игре не проверено:** появление карт в выборе Conquest, запуск атаки/обороны, фактическая проходимость между позициями, столкновения укреплений с деревьями и зданиями, линии огня и длительный бой. Навигационная сетка подтверждает тип/уклон грунта, но не заменяет проверку препятствий и маршрутов в редакторе. Повторно использованные укрепления могут потребовать локальной доводки после такой проверки.

Для воспроизведения генерации нужны извлечённые исходные `map`/`map.net` в рабочем каталоге `_survival_work/conquest-maps-20261007` и текущие миссии UFB; игровые архивы в Git не копируются:

```powershell
node tools/expand-conquest-maps.cjs ../_survival_work/conquest-maps-20261007 --rebuild
node tools/test-conquest-maps.cjs
node tools/validate-mission-ai.cjs
node tools/package-conquest-maps.cjs
```

Установка использует существующий `tools/Apply-TacticalPatch.ps1` и пакет `../_survival_work/conquest-maps-20261007/package`. Перед применением игра и редактор должны быть закрыты. Девять файлов установлены, хеши сверены; установленный каталог содержит 117 миссий Conquest.

В этой сессии установка прошла в два этапа. Для полного отката используйте `-RollbackBackup` сначала с `package/backups/20261006-232456-4418757` (возврат трёх миссий до переноса дополнительных точек HF), затем с `package/backups/20261006-232240-2791680` (удаление девяти добавленных файлов). Пути относительны каталогу пакета. Без `-Apply` выполняется только проверка; с `-Apply` — откат. Установщик проверяет хеши и сохраняет исходные multiplayer-карты. Будущие установки создадут собственные резервные копии.
