## Настройка и откат

`tools/battlefield-persistence.json`: enabled, metalParticleSeconds (3600), sandbagParticleSeconds (99999), лимиты трёх групп. Перегенерация — `node tools/build-battlefield-persistence.cjs`; генератор отказывается перезаписывать последующие неизвестные ему изменения. При enabled=false возвращает исходные определения и делает включённый обработчик пустым. Скопировать новые ресурсы в игру нужно отдельно через проверяемый пакет. Срок жизни эффекта и лимит группы — разные ограничения; ни один из них не обещает бесконечного сохранения каждой частицы.

Шанс ранения настраивается в `set/interaction_entity/human.inc`, обработчик personage_check, `rand 0.30` — шанс запрета спасаемого состояния среди допустимых MP-случаев. Для отката крови восстановить шесть .def из резервной копии и удалить два добавленных переопределения bloodstain_rot120/240.def, чтобы снова использовались версии BM. Эти варианты тоже заменены штатной текстурой GoH: если их вызывает модовая модель, огромная BM-лужа больше не должна появляться. Радиус медика находится в `map/multi/HF-dcg_script.inc`, обработчик `hf medic ai/heal`.

Откат установленного пакета: `tools/Apply-TacticalPatch.ps1 -Package <каталог пакета> -RollbackBackup <каталог backups/... с rollback.json> -Apply`, при закрытой игре. Предварительная проверка без `-Apply` ничего не меняет. Не следует переустанавливать старый общий пакет поверх нового патча.
