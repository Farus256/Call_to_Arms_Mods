# Исправление вылета ДК при загрузке waypoint — 09.10.2026

Свежий `game.log` подтверждает исключение `Can't use waypoint id, it already used`
при загрузке `dcg_f_bridges_of_lysovo/campaign_capture_the_flag.mi`, строки 1518
подключённого `ufb_garrison_layout.inc`, ID `11021`. Бой и Lua ИИ к этому моменту
ещё не запущены. В логе также есть 13 предупреждений о костях `enumerator` у моделей
техники; они не являются указанным фатальным исключением.

Причина — превышение ёмкости числового реестра waypoint. В установленной игре
1.067.0 инициализатор по адресу `0x140070a90` передаёт `0x2000` (8192) в конструктор
аллокатора `0x1405543d0`. Конструктор waypoint `0x140996320` распознаёт числовое имя
и передаёт его в резервирование `0x140554580`, которое обращается к битовой таблице
по индексу `ID >> 5` без проверки верхней границы. Старая формула
`10000 + entrance * 1000 + originalID` обращалась за пределы этой таблицы.
Ошибка «ID уже используется» здесь не доказывает наличие одинаковых строк в карте.

Новая формула: `1200 + (entrance - 1) * 850 + originalID`. Авторские ID гарнизонов
во всех 117 картах не превышают 736, штатные и HF ID — 1090. Максимальный фактически
используемый новый номер — 7874; все номера укладываются в диапазон `0..8191`.
Переименованы 296 868 определений и 353 548 ссылок в 117 файлах расстановки
и двух общих сценариях маршрутизации. Обратная замена номеров побайтно восстанавливает
каждый исходный файл: координаты, радиусы, команды, задержки и расчёт увеличенных
дальностей сохранены. Файлы самих миссий `.mi` не изменены.

Отдельно исправлена ошибка предыдущей правки дыма: `local_offset 1000 0 0` задавал
50 м, поскольку 20 единиц координат равны метру. Теперь три события используют
`local_offset 200 0 0`, то есть 10 м. Проверка вычисляет расстояние из фактического
вектора ресурса и сравнивает его с дальностями всех 14 дымовых гранат.
Штатный комментарий `value / 20 = meters` взят из текущего `gamelogic.pak`,
`set/third_person/vehicle_specific_ger_tank.inc`, строки 6–7.

Проверено:

- Все 117 карт: 374 010 waypoint с раскрытием подключённых файлов HF;
  числовые ID допустимы и уникальны, все ссылки гарнизона разрешаются,
  цепочки разных входов изолированы.
- Исходные 114 карт: 912 входов и 289 284 подготовленные точки;
  исходные команды и содержание миссий сохранены. Прежние ограничения
  дистанций для техники на тесных картах остаются отражены в отчёте расстановки.
- Три добавленные карты: 24 входа, 3063 объекта, 9555 точек и 179 связей укрытий;
  проверки навигации и штатных оборонительных слотов прошли.
- Проверка сценариев: 564 файла, 117 карт с гарнизонами, 16 регрессионных условий,
  ошибок нет. Проверка ИИ пехоты: три дымовых сценария, три задачи укрытия
  и семь исполняемых сценариев Lua прошли, включая отступление и конец игры.
- Все 11 164 файла исходников совпадают с установленным UFB. Изменены 120 файлов;
  11 044 остальных ресурса сохранены. Наборы отрядов HF и текущие модули
  штатного ИИ не изменены этим исправлением.

Новая проверка `tools/test-waypoint-loading.cjs` воспроизводила отказ на старых
ресурсах и проходит после исправления. `tools/validate-mission-ai.cjs`,
`tools/test-garrison-layout.cjs` и `tools/test-conquest-maps.cjs` теперь проверяют
диапазон ID и точки из подключённых файлов. Генератор также запрещает номера
за пределами своего блока и ёмкости движка.

Исправление установлено в игру. Пакет, снимок лога, доказательство сохранности,
данные координат и разбор числового реестра находятся в
`../_ai_work/waypoint-crash-fix-20261009` относительно репозитория.
Резервная копия: `backups/20261009-151546-3030872` внутри пакета.
Предварительная проверка отката всех 120 файлов прошла.

Игра после установки не запускалась: фактическая загрузка карты и бой ещё
требуют повторного запуска ДК. Проверки файлов не подменяют проверку в движке.
Для отката из каталога репозитория:

```powershell
.\tools\Apply-TacticalPatch.ps1 -Package ..\_ai_work\waypoint-crash-fix-20261009 -RollbackBackup ..\_ai_work\waypoint-crash-fix-20261009\backups\20261009-151546-3030872 -Apply
```

Откат выполняется при закрытой игре и возвращает прежнюю, ошибочную нумерацию.
Если нужен полный откат предыдущих правок ИИ, сначала откатывается этот пакет,
затем более ранние пакеты в обратном порядке установки.
