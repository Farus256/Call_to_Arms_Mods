# Наблюдения о реализме HF 4.0.0 — 05.11.2026

**Обновление после аудита:** реакция на молчащий пулемёт, преждевременная подготовка ПТ-оружия и перечисленные кривые пробития исправлены в [пакете 13 пунктов](LOGIC_FIXES_20261105_RU.md). Таблица ниже сохраняет исходные наблюдения; здоровье ветеранов и преимущества прямого управления не перенастраивались.

Проверены связанные с текущей задачей механики пехоты, ПТ-оружия, выбора целей и защитных реакций. Ниже перечислены подтверждённые настройки и варианты изменения. Оценка реалистичности — инженерное суждение; это не полный исторический аудит всех юнитов HF. После этого аудита по запросу пользователя установлены исправления, описанные в [отчёте по восьми пунктам](COMBAT_REVIEW_20261105_RU.md), включая пробитие Panzerfaust 60 и короткое подавление пулемётом. Варианты из таблицы оставшихся наблюдений не применены.

## Что уже исправлено в текущей доработке

В `set/target/human_fg.inc` прежний список ставил танки и орудия раньше пехоты при уже взятой в руки осколочной гранате. Теперь близкая пехота имеет приоритет. Для осколочных гранат по целям в укрытии добавлена штатная проверка `check_grenade`, уже использовавшаяся в остальных пехотных ветках. Новая инициативная автоматика дополнительно проверяет союзников возле цели. После повторной проверки сохранены штатные строки уже подготовленного ПТ-оружия у ботов и ручной выбор гранатомёта игроком; дополнительный автоматический выбор из инвентаря предпочитает пригодное стрелковое оружие.

У Panzerfaust 60 прежняя таблица `{41 200} {46 0}` заменена по выбранному пользователем варианту: 200 мм у ствола → 180 мм на 20 м → 160 мм на 40 м. Дальность 40 м и остальные поля оружия сохранены. Падение линейное, без прежнего обрыва на 41–46 м.

Реакция HF на пулемёт и выбор дистанции ПТ-атаки остаются кандидатами на отдельную проверку: они могут менять поведение без возврата старых HP, урона или дальностей UFB. Новое короткое продолжение огня по последней видимой позиции не заменяет защитную реакцию HF из таблицы. Здоровье ветеранов и преимущества прямого управления остались штатными. Пробитие Panzerfaust 60 изменено по согласованию выше.

Исходные значения взяты из свежей локальной базы игры + HF 4.0.0: `_survival_work/hf-update-20261105/reference/resource` рядом с репозиторием. Штатный HF-скрипт с сохранёнными доработками находится в установленном UFB. Новый игровой прогон для измерения влияния перечисленных вариантов не проводился.
