# Дополнение к настройкам реализма — 2026-10-02

## Изменения в активном Ultimate Frontline Bundle

Изменён `resource/map/multi/HF-dcg_script.inc` — общий скрипт Horten's Frontline, который уже перекрывает более ранние AI-правки в профиле загрузки.

- Поиск раненых медиком: максимальная дистанция 90 → 45 м. Это уменьшает забеги медика через открытую местность, сохраняя автоматический поиск ближайших раненых.
- Противотанковая граната: порог начала атаки 18 → 12 м. Бросок начинается только на близкой дистанции.
- Пауза между повторными атаками противопехотной гранатой: 12 → 18 с.
- Пауза между повторными атаками противотанковой гранатой: 10 → 18 с.

Оставлены без изменений уже действующие правки: видимая цель для противопехотной гранаты; снятый запрет отступления у обходящей пехоты; отсутствие искусственной выдачи 200 выносливости; исключения экипажей, медиков, ремонтников и занятых/раненых бойцов из навязанных атак. Новые значения меняют поведение AI-скрипта Horten's Frontline для поддерживаемых им режимов; глобальные свойства бойца не менялись, поэтому сюжетные миссии не затрагиваются.

## Переключатель кругов снабжения и лечения

Универсальную кнопку в «Дополнительных параметрах» этим изменением не добавлял. Проверка ресурсов не выявила подтверждённого общего игрового действия, которым можно одним флажком скрывать одновременно круг автоматического лечения медика и окружности снабжения техники, ящиков и палатки. Это разные механизмы: круг медика связан с действием интерфейса, а снабжение определяется свойствами объектов/зон. Добавлять неподтверждённое действие было бы риском получить видимую кнопку без эффекта либо изменить поведение снабжения.

Для реализации этой части нужна подтверждённая точка расширения интерфейса/скриптов игры, которая управляет отображением обоих типов окружностей. Пока такая команда не найдена, конкретный переключатель и его вкладка не созданы.
